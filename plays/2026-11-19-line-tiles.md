# 2026-11-19 線のベクタタイルの比較（terrio 0.9.0 と tippecanoe 2.49.0）

- 入力: opengeos/data の国界を輪郭線 284 本にしたもの、乱数歩行の線 3,000 本（各 61 頂点、138〜142°E・34〜38°N）
- 方法: terrio で `--minzoom 0 --maxzoom 6` の PMTiles、tippecanoe で `-Z0 -z6` の PMTiles、GDAL の MVT。terrio と tippecanoe の PMTiles を GDAL 3.13.3 の PMTiles ドライバーで読み、ズームごとの地物数・頂点数・総延長を数えた

## 結果

| 入力 | z | terrio（地物, 頂点, km） | tippecanoe |
|---|---|---|---|
| 国界の線 | 0 | 284, 9,958, 1,048,195 | 284, 8,578, 1,049,559 |
| 同 | 6 | 1,682, 13,928, 1,046,537 | 1,682, 13,830, 1,046,532 |
| 乱数歩行 | 0 | 2,865, 25,179, 221,285 | 2,020, 4,040, 23,111 |
| 同 | 2 | 3,000, 82,774, 206,684 | 2,997, 12,980, 59,067 |
| 同 | 4 | 3,000, 171,823, 177,976 | 3,000, 89,994, 152,010 |
| 同 | 6 | 3,088, 190,363, 172,087 | 3,087, 165,107, 171,121 |

アーカイブ: 国界 376 KB（terrio）対 391 KB（tippecanoe）、乱数歩行 911 KB 対 733 KB。

## 発見

1. 実データの線（国界）は、tippecanoe とほぼ同じ（地物数は一致、頂点数も近い）。
2. 画素より小さい細部が多い線は、tippecanoe が低ズームで大きく簡略化し、terrio は量子化が中心で、頂点が多く残る。
3. GDAL 3.13.3 は、自分が書いた MVT ディレクトリを `OpenEx` で開けなかった（3.8.4 と同じ。原因未確認）。
