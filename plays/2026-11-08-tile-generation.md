# 2026-11-08 ベクタタイル書き出しの掘り下げ（tippecanoe・GDAL との比較）

- 日付: 2026-11-08。terrio 0.7.0（PyPI の wheel）、tippecanoe 2.49.0（apt）、GDAL 3.8.4（apt、`ogr2ogr -f MVT`）
- ドキュメント（`docs/formats.md`）: terrio のベクタタイル書き出しは **GDAL の MVT ライターの再現**（EPSG:3857、既定ズーム 0〜5、80/4096 の余白、量子化、500 kB 超は低解像度に）。
- 入力: opengeos/data の `countries.geojson`（179 地物の多角形）、乱数で作った 6 万点（日本語の属性つき）

## 結果

| 入力 | terrio | GDAL の MVT | tippecanoe |
|---|---|---|---|
| 国界、z0〜4 の地物数 | 178・199・221・281・436 | 同じ（terrio が読んだ値） | 同じ（z0・z2・z4 で確認） |
| 国界のサイズ | 166,437 B（PMTiles） | 170,158 B（ディレクトリ） | 155,174 B（PMTiles） |
| 6 万点、z0 / z2 / z4 / z6 の地物数 | 60,000 / 46,200 / 45,600 / 60,025 | 60,000 / 48,600 / 48,600 / 60,025 | **246 / 1,536 / 9,600 / 60,025** |
| 6 万点のサイズ | 3.55 MB | （比較せず） | 1.61 MB（`--drop-densest-as-needed` でも同じ） |

## 発見

1. **多角形では 3 者の地物数が一致**した。terrio の書き出しは GDAL の再現というドキュメントが実測と合った。
2. **点の密度による間引きは terrio に無い**。z0 に 6 万点がすべて入る。tippecanoe は z0 で 246 点に間引く。dwg7 が tippecanoe を使う目的が間引き・自動の最大ズームなら、まだ置き換えられない。
3. GDAL の MVT ライターと terrio は、密な点の z2・z4 で 5% ほど違う（48,600 と 46,200／45,600）。500 kB 超のタイルの扱いの差と思われるが、**未確認**。
4. GDAL 3.8.4 は自分が書いた MVT ディレクトリを `gdal.OpenEx` で開けなかった（`not recognized`）。terrio は開けた。原因は未確認（この GDAL のビルドの事情か）。
5. 未確認: 線の簡略化、MapLibre での見え方、百万地物、`terrio tile`（ラスタ）。
