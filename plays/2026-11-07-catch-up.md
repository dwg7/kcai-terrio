# 2026-11-07 terrio のキャッチアップ（0.7.0 で動かしていなかった領域）

- 日付: 2026-11-07。terrio **0.7.0**（PyPI の wheel、Linux x86_64。PyPI・crates.io・npm とも最新は 0.7.0）。main は `c964352`（0.7.0 から 55 コミット先）
- 目的: 11-04 の確認で、見出しと CHANGELOG を読んだだけだった領域を、動かして確かめる。main の先行分は読むだけ

## 動かしたこと（played）

| 項目 | 結果 |
|---|---|
| OGC API Features（pygeoapi の demo、`lakes`） | `info` が通る。`--limit 4 --oo PAGE_SIZE=3` で GeoPackage へ変換でき、ページ送り（offset=3）の要求が出る |
| WFS（demo.mapserver.org、1.1.0） | `info` が層（`continents` ほか 2 層）を列挙する |
| STAC の `method=POST`（Earth Search、東京、`max_items=1`） | 3 要求・6.14 MiB。512×512、EPSG:32654 |
| 遠隔 Zarr（NOAA HRRR、`AWS_NO_SIGN_REQUEST=YES`、`ZARR:"/vsis3/…"`） | `info` が通る（1799×1059、座標系は unknown） |
| GRIB（NOAA GFS 0.25°、公開 S3） | `info` は 696 バンド、**713 要求・6.94 MiB**。1 バンドの窓 64² を取り出すと 714 要求・7.75 MiB（約 +0.8 MiB） |
| 等高線（`contour --interval 10`、DEM 140×140） | 106 本。`gdal_contour -i 10` も 106 本 |
| SQL | `GROUP BY` と `COUNT` / `SUM`、`ST_Area` が期待どおり |
| `terrio.dev/web`（ブラウザの CLI） | 実ブラウザで読み込み。「Terrio v0.7.0」、コマンド一覧が出る。コンソールのエラーなし |

## 動かさなかったこと

STACTA、`terrio.dev/web` でのコマンドの実行、`preview` の画像の中身（`-o FILE` が要る）、`viewshed`、`zonal-stats` の値（試料の多角形がラスタと重ならず count 0）、新しい点群フィルタの値、main の先行分。

## main（0.7.0 の後、55 コミット）の読み

性能の改善（Deflate 書き込みを libdeflate 1.26 の**純 Rust 移植**に。zlib-rs から。バイト一致を確認したと作者）、HTTP 接続プールの共有、`dem`・`zonal`・`warp` の高速化、`terrio.dev/web`、タイル生成の拡張、KMZ・FlatGeobuf・GeoPackage の堅牢化、新しい貢献者（Nicolas Karasiak、Eduardo Lacerda ほか）。**新しい版はまだ出ていない**。

## 発見

1. 0.7.0 の新しい入力（GRIB・遠隔 Zarr・OGC API Features・WFS・STAC POST）は、公開サーバーに対して実際に動いた。
2. GRIB の `info` は 713 要求（メッセージごとの 16 KiB）で、要求数が多い。窓の取り出しの追加は小さい。
