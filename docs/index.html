kcai-terrio：ブラウザで terrio を遊ぶ

terrio（Qiusheng Wu さん作、MIT）を WebAssembly（terrio-js）でこのページに読み込みます。 データを取りに行くのはあなたのブラウザです（相手側の CORS 設定に左右されます）。 踏み跡は 下の一覧（knowledge/）、まず読むなら dwg7 に対する助言、遊びの記録は plays/。

3. 日本語の文字列は通るか

terrio 0.3.2 の CLI は、日本語の長い文字列を含む GeoJSON / CSV で panic しました（0.4.0 で修正済み）（opengeos/terrio#159）。WebAssembly 版ではどうなるかを、あなたのブラウザで確かめます。
